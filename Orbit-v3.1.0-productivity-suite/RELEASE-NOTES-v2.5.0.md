# Orbit v2.5.0 — Focus Analytics

## Focus Intelligence upgrades
- Redesigned analytics dashboard with higher-contrast metric cards, compact visual hierarchy, usage bars, and responsive layouts.
- Seven-day activity chart based on locally stored daily history.
- Heuristic website category breakdown: Work, Learning, Social, Entertainment, and Other.
- Configurable daily browsing-time goal with progress indicator, saved locally.
- Built-in focus sprint timer (15, 25, 45, or 60 minutes) with pause/resume/reset.
- Export today's domain-level usage as CSV.
- Top-site insight and per-domain share of today's tracked time.

## Data and limitations
- Analytics are based on active-domain duration events received from the optional Chromium extension while Orbit is running.
- No page content, titles, or full URLs are collected.
- Category labels are heuristics, not authoritative classifications.
- The seven-day chart shows only recorded history; it does not backfill time from before tracking was enabled.
- The focus sprint timer is a simple in-app timer, not an OS-wide focus lock.
