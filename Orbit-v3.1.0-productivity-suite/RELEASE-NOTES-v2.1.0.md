# Orbit v2.1.0 — Bounded Agent Task Runner

## New in this release

- AI-assisted task planning with the configured local Ollama or OpenAI-compatible provider.
- Optional project excerpts from the selected project folder are included as untrusted context when available.
- A review-before-execution flow: planning never runs project commands.
- Sequential execution of only fixed allowlisted actions: Git status, Git diff summary, recent Git commits, and `npm run build`.
- One explicit confirmation lists the selected actions and target project folder before execution begins.
- Actual command output and per-step success/failure are displayed. The UI explicitly warns users not to treat a plan or model claim as execution evidence.
- Recent task runs are stored locally (up to 20) and can be restored for review without re-execution.

## Safety boundaries

- This release does **not** autonomously edit source files.
- It does **not** execute arbitrary shell commands generated by the model.
- Commands run only within the project folder selected through Orbit's folder picker, and each action ID must match the Electron main-process allowlist.
- The task planner's model output is advisory. Command output is the source of truth for whether an action succeeded.

## Retained capabilities

Existing Orbit v2.0 functionality remains: model routing/fallback configuration, streaming responses, named conversations, keyword-based project retrieval, approval-gated Git/build actions, clipboard capture, prompt templates, prompt history, and Markdown export.

## Verification status

- Electron main/preload JavaScript syntax checks: run before packaging.
- TypeScript/JSX transpilation checks: run before packaging.
- ZIP integrity: run before delivery.
- Full `npm run build` requires dependency installation. If registry access is unavailable, a full build cannot be claimed as verified.
